# ИИ-администратор стоматологии (Telegram)

Отвечает на вопросы о ценах и врачах, записывает, переносит и отменяет приёмы, напоминает за сутки,
передаёт сложные случаи живому администратору. Работает круглосуточно.

Только стандартная библиотека Python 3.9+, без зависимостей. Модель — любая с OpenAI-совместимым API
(DeepSeek, OpenRouter, YandexGPT, OpenAI), меняется в `config.json`.

## Файлы

| Файл | Что внутри |
|---|---|
| `clinic.json` | База клиники: врачи и их расписание, услуги и цены, частые вопросы. Новая клиника = новый файл |
| `agent.py` | Правила поведения (промпт) и цикл вызова инструментов |
| `tools.py` | Инструменты модели: окна, запись, мои записи, отмена, позвать администратора |
| `schedule.py` | Свободные окна, запись без двойного бронирования, напоминания |
| `bot.py` | Telegram: диалоги пациентов, уведомления и команды администратора |
| `test_offline.py` | Проверки без сети и ключей |
| `dialogs.py` | Живой прогон 8 сценариев на настоящей модели |

## Запуск

```bash
cp config.example.json config.json   # вписать токен бота, chat_id администратора, ключ модели
python3 test_offline.py
python3 dialogs.py
python3 bot.py
```

Чат администратора получает новые записи, отмены и вызовы; команды там: `/today`, `/tomorrow`, `/week`, `/cancel N`.
